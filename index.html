Use BeGirl9 on Another Device

The HTML file is standalone. Copy it to another phone, tablet, Windows PC, or Mac. Your sales and settings are stored separately on each device, so use Backup / Restore to move your data.

Step 1 — On this device
Tap Backup Data to download one backup file containing your products, sales, held sales, business branding, currency, promotions, and last receipt.
Step 2 — On the other device
Open the same BeGirl9 HTML file, go to Settings, choose Restore Data, and select the backup file.
